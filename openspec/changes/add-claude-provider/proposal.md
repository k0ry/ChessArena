## Why

ChessArena умеет сажать за доску Grok, ChatGPT и Gemini, но не Claude, хотя модели Anthropic входят в число сильнейших по рассуждению. Пользователь хочет назначать Claude любому участнику эфира: белым, чёрным и комментатору, с отдельным выбором модели для каждого, используя собственный API-ключ Anthropic.

## What Changes

- Добавить провайдера **Claude** в независимый выбор нейросети для белых, чёрных и рефери/комментатора, включая любые сочетания с существующими провайдерами и Claude против Claude с разными моделями.
- Подключить Anthropic Messages API через отдельный маршрут транспорта: формат запроса и ответа Anthropic отличается от Chat Completions, поэтому существующий HTTP-транспорт не переиспользуется напрямую.
- Хранить API-ключ Anthropic в Keychain отдельно от ключей xAI и OpenAI; показывать панель подключения, только если Claude выбран хотя бы одним участником.
- Предлагать каталог моделей аккаунта через Models API после ввода ключа, с возможностью обновить список и ввести ID модели вручную. Модель по умолчанию: `claude-opus-5-5`.
- Регулировать глубину рассуждения через параметр `effort`: выше для игрока, ниже для комментатора, чтобы комментарий укладывался в текущий тайм-аут ведущего.
- Преобразовывать ошибки Anthropic (аутентификация, доступ к модели, лимиты, перегрузка, отказ модели) в существующие безопасные категории без раскрытия ключа и без бесконечных автоповторов.
- Сохранять выбор Claude и моделей в сессии; старые файлы сессии SHALL продолжать открываться без изменений.
- Проверить работу Claude за игрока и за комментатора фиктивным сервером и живым запросом с ключом пользователя.

Доступ через подписку Claude (локальный Claude Code CLI) в это изменение не входит и может быть оформлен отдельным change по образцу Gemini.

## Capabilities

### New Capabilities

- `ai-players`: требования к игроку Claude: независимый выбор для каждой стороны, ключ Anthropic в Keychain, каталог и выбор модели, обработка ошибок Anthropic и продолжение партии после паузы.
- `match-host`: требования к комментатору Claude: выбор провайдера и модели для ведущего, соблюдение тайм-аута ведущего и резервная реплика при ошибке Anthropic.

В `openspec/specs/` пока нет опубликованных capabilities. Пути `ai-players` и `match-host` уже используются незавершённым change `ai-chess-broadcast`, а `ai-players` ещё и change `add-gemini-subscription`. Здесь эти пути сохранены, требования добавляются под собственными именами. Перед архивацией изменений наборы требований нужно сверить и объединить, не потеряв исходные.

### Modified Capabilities

Нет опубликованных capabilities для изменения.

## Impact

- `Sources/ChessArenaCore/PlayerConfiguration.swift`: новый `case claude` в `NeuralProvider`, модель и адрес по умолчанию, передача ключа в `Seat`.
- `Sources/ChessArenaCore/Chat.swift`: новый маршрут `ChatRoute`, каталог моделей Anthropic, вторая таблица классификации ошибок, парсер ответа Messages API.
- `Sources/ChessArenaCore/ChatGPTTransport.swift` (`ArenaChatTransport`): ветка маршрута Anthropic с заголовками `x-api-key` и `anthropic-version`.
- Новый файл подключения Claude в `Sources/ChessArenaCore/`: загрузка каталога моделей и статус подключения, по образцу `GeminiConnection`.
- `Sources/ChessArena/MatchRuntime.swift`: третий ключ в Keychain, флаг `needsClaude`, валидация перед стартом и продолжением, передача ключа в `Seat`.
- `Sources/ChessArena/ControlView.swift`: Claude в пикере всех трёх участников, панель ключа и каталога моделей.
- `Sources/ChessArenaCore/SessionStore.swift`: новый raw value провайдера сохраняется без смены схемы.
- `Tests/ChessArenaCoreTests/`: тесты транспорта Anthropic на `MiniHTTPServer`, классификации ошибок, конфигурации игроков и сохранения сессии.
- `README.md`: раздел о подключении Claude.
- Зависимость: change `add-gemini-subscription` не завершён и меняет те же файлы конфигурации и управления. Реализацию Claude следует начинать после его завершения или явной заморозки, чтобы не разводить правки одних и тех же мест.
