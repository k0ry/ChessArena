## Why

ChessArena умеет сажать за доску Grok, ChatGPT и Gemini, но не Claude, хотя модели Anthropic входят в число сильнейших по рассуждению. Пользователь хочет назначать Claude любому участнику эфира: белым, чёрным и комментатору, с отдельным выбором модели для каждого. Основной способ доступа — подписка Claude через установленный на Mac официальный Claude Code CLI, по образцу Gemini; собственный API-ключ Anthropic остаётся альтернативой.

## What Changes

- Добавить провайдера **Claude** в независимый выбор нейросети для белых, чёрных и рефери/комментатора, включая любые сочетания с существующими провайдерами и Claude против Claude с разными моделями.
- Добавить явный режим доступа Claude с переключателем, как у ChatGPT: **подписка** (по умолчанию) или **API-ключ**. Режим сохраняется в сессии.
- Режим подписки: запускать установленный локально официальный Claude Code CLI в неинтерактивном режиме с JSON-выводом, без инструментов, MCP, пользовательских настроек и сохранения сессий; вход выполняется штатным сценарием CLI в локальном терминале, приложение не читает и не переносит токены. Проверять версию CLI, наличие входа по подписке и отсутствие режима API-ключа в CLI до отправки хода.
- Режим API-ключа: подключить Anthropic Messages API через отдельный маршрут транспорта: формат запроса и ответа Anthropic отличается от Chat Completions, поэтому существующий HTTP-транспорт не переиспользуется напрямую. Ключ хранится в Keychain отдельно от ключей xAI и OpenAI.
- Выбор модели: в режиме подписки — алиасы актуальных моделей CLI (`opus`, `sonnet`, `haiku`) и ручной ввод полного ID; в режиме API-ключа — каталог аккаунта через Models API и ручной ввод. Модель по умолчанию: `claude-opus-5-5`. Панель подключения показывается, только если Claude выбран хотя бы одним участником.
- Регулировать глубину рассуждения через параметр `effort`: выше для игрока, ниже для комментатора, чтобы комментарий укладывался в текущий тайм-аут ведущего.
- Преобразовывать ошибки Anthropic и CLI (вход, доступ к модели, лимиты подписки, перегрузка, отказ модели, отсутствие или несовместимость CLI) в безопасные категории без раскрытия ключа и токенов. Ошибки CLI и отказ модели ставят партию на паузу без автоповтора, HTTP-ошибки повторяются по общим правилам.
- Сохранять выбор Claude и моделей в сессии; старые файлы сессии SHALL продолжать открываться без изменений.
- Проверить работу Claude за игрока и за комментатора фиктивным сервером, фиктивным CLI и живым запросом с аккаунтом пользователя.

## Capabilities

### New Capabilities

- `ai-players`: требования к игроку Claude: независимый выбор для каждой стороны, режим доступа (подписка через локальный CLI или API-ключ), вход по подписке без переноса токенов, ключ Anthropic в Keychain, каталог и выбор модели, обработка ошибок и продолжение партии после паузы.
- `match-host`: требования к комментатору Claude: выбор провайдера и модели для ведущего, соблюдение тайм-аута ведущего и резервная реплика при ошибке Anthropic.

В `openspec/specs/` пока нет опубликованных capabilities. Пути `ai-players` и `match-host` уже используются незавершённым change `ai-chess-broadcast`, а `ai-players` ещё и change `add-gemini-subscription`. Здесь эти пути сохранены, требования добавляются под собственными именами. Перед архивацией изменений наборы требований нужно сверить и объединить, не потеряв исходные.

### Modified Capabilities

Нет опубликованных capabilities для изменения.

## Impact

- `Sources/ChessArenaCore/PlayerConfiguration.swift`: новый `case claude` в `NeuralProvider`, модель и адрес по умолчанию, передача ключа в `Seat`.
- `Sources/ChessArenaCore/Chat.swift`: новый маршрут `ChatRoute`, каталог моделей Anthropic, вторая таблица классификации ошибок, парсер ответа Messages API.
- `Sources/ChessArenaCore/ChatGPTTransport.swift` (`ArenaChatTransport`): ветка маршрута Anthropic с заголовками `x-api-key` и `anthropic-version`.
- Новые файлы в `Sources/ChessArenaCore/`: `ClaudeCLI.swift` (запуск и разбор ответа Claude Code CLI через `LocalCLIProcess`, по образцу `GeminiCLI`), `AnthropicTransport.swift` (Messages API и Models API), `ClaudeConnection.swift` (состояние подключения обоих режимов: путь к CLI, вход, проверка, каталог по ключу).
- `Sources/ChessArena/MatchRuntime.swift`: третий ключ в Keychain, флаг `needsClaude`, валидация перед стартом и продолжением, передача ключа в `Seat`.
- `Sources/ChessArena/ControlView.swift`: Claude в пикере всех трёх участников, панель ключа и каталога моделей.
- `Sources/ChessArenaCore/SessionStore.swift`: новый raw value провайдера и необязательное поле режима доступа Claude сохраняются без смены схемы.
- `Tests/ChessArenaCoreTests/`: тесты транспорта Anthropic на `MiniHTTPServer`, тесты CLI на фиктивном исполняемом файле, классификации ошибок, конфигурации игроков и сохранения сессии.
- `README.md`: раздел о подключении Claude.
- Зависимость: change `add-gemini-subscription` не завершён и меняет те же файлы конфигурации и управления. Реализацию Claude следует начинать после его завершения или явной заморозки, чтобы не разводить правки одних и тех же мест.
