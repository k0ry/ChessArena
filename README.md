# ChessArena

Нативное шоу для macOS: Grok против ChatGPT, отдельное окно сцены для OBS и окно управления.

## Запуск

Откройте `ChessArena.app` в папке проекта. Чтобы пересобрать приложение:

```sh
./scripts/build-app.sh
```

1. Введите ключ xAI для Grok и ведущего.
2. Нажмите **Continue with ChatGPT**. В системном браузере войдите в аккаунт и разрешите ChessArena использовать план ChatGPT.
3. Вернитесь в приложение. Дождитесь «Подключено» и выберите модель из каталога аккаунта.
4. Нажмите **Начать игру**. Наличие модели в каталоге не гарантирует оставшуюся квоту: если запрос отклонён, причина появится в управлении, а сцена покажет паузу.
5. После устранения причины нажмите **Продолжить**. Повторяется ход той же стороны с сохранённой позиции.

Вход использует официальный OAuth для локальных приложений, PKCE, проверку state/nonce и подписи ID token. Возврат — на локальный адрес `127.0.0.1` со случайным портом. Сессия ChessArena хранится отдельно в Keychain; приложение не читает авторизацию Codex или браузерные cookies. Доступ к плану зависит от аккаунта и разрешений OpenAI. Если macOS запрашивает доступ к связке ключей, подтвердите его в системном окне.

Альтернативный режим — собственный API-ключ OpenAI; он включается переключателем в управлении. API-ключ и вход через ChatGPT используют разные способы оплаты и доступа.

## Сцена

Металлические фигуры с голубыми и янтарными световыми акцентами, узнаваемые силуэты, плавные ходы и неоновая платформа. Взятия, рокировка, превращение и взятие на проходе отображаются из принятой судьёй позиции.

OBS: захват окна **ChessArena Program**, звук — отдельным захватом приложения. Архивы сохраняются в `~/Documents/ChessArena/`.

## Проверка

```sh
swift test
.build/debug/ChessArena --preview Preview/arena.png
```

Тесты используют фиктивные ответы и локальный HTTP-сервер, не расходуют квоту моделей. Metal, кодеки и Keychain требуют обычного локального запуска вне ограниченной песочницы.

Живой OAuth требует входа пользователя в браузере. Автоматические проверки не подтверждают права конкретного аккаунта или завершённую живую партию.

Документация: https://developers.openai.com/siwc/token-sharing-open-source/sign-in
