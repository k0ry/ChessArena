# ChessArena

Нативное шоу для macOS: шахматные партии между Grok и ChatGPT в любой комбинации, отдельное окно сцены для OBS и окно управления.

## Запуск

Откройте `ChessArena.app` в папке проекта. Чтобы пересобрать приложение:

```sh
./scripts/build-app.sh
```

1. Выберите нейросеть отдельно для белых и чёрных: Grok или ChatGPT. Можно выбрать одну нейросеть для обоих игроков. Введите ключ xAI для ведущего и игроков Grok; модель ведущего настраивается отдельно.
2. Если выбран игрок ChatGPT, нажмите **Continue with ChatGPT**. В системном браузере войдите в аккаунт и разрешите ChessArena использовать план ChatGPT.
3. Вернитесь в приложение. Дождитесь «Подключено» и выберите модель из каталога аккаунта отдельно для каждого игрока ChatGPT. Для Grok и режима API укажите ID модели в поле игрока.
4. Выберите **Язык эфира и озвучки**: русский или английский. Выбор сохраняется; реплики игроков, ведущий, резервные фразы и системный голос используют выбранный язык. Кнопка **Проверка тона** позволяет прослушать голос до старта.
5. Нажмите **Начать игру**. Начнётся непрерывная серия партий. **Стоп** отменяет запросы, останавливает звук и отключает запуск следующей партии.

Зависший запрос игрока отменяется через 10 минут (600 секунд). Ошибки соединения и API повторяются автоматически с той же позиции через 3, 6, 12, 24, 48, затем 60 секунд. Запоздавший ответ отменённого запроса не делает ход. Ошибка ключа или квоты остаётся видна в управлении: автоповтор не восстанавливает права доступа, но продолжит игру после исправления подключения. У ведущего отдельный тайм-аут 12 секунд с резервной фразой на выбранном языке.

Общий счёт постоянно виден сверху по центру. Победа приносит одно очко, ничья — по половине. Счёт сохраняется для выбранной пары игроков между запусками; сброс доступен после остановки. После завершения партии появляется заставка победителя или ничьей со счётом и отсчётом: через 30 секунд автоматически стартует новая партия. Остановка во время отсчёта отменяет перезапуск. Для каждой партии создаётся отдельный архив.

Нейросеть выбирается до начала партии; модель можно исправить на паузе перед продолжением. Кнопка **Закрыть приложение** внизу окна управления (⌘Q) завершает приложение целиком, включая окно сцены.

Вход использует официальный OAuth для локальных приложений, PKCE, проверку state/nonce и подписи ID token. Возврат — на локальный адрес `127.0.0.1` со случайным портом. Сессия ChessArena хранится отдельно в Keychain; приложение не читает авторизацию Codex или браузерные cookies. Доступ к плану зависит от аккаунта и разрешений OpenAI. Если macOS запрашивает доступ к связке ключей, подтвердите его в системном окне.

Альтернативный режим — собственный API-ключ OpenAI; он включается переключателем в управлении. API-ключ и вход через ChatGPT используют разные способы оплаты и доступа.

## Сцена

Партия идёт без периодических обзоров и пауз каждые пять минут. Итоговая карточка появляется только после завершения игры.

Металлические фигуры с голубыми и янтарными световыми акцентами, узнаваемые силуэты, плавные ходы и неоновая платформа. Взятия, рокировка, превращение и взятие на проходе отображаются из принятой судьёй позиции.

OBS: захват окна **ChessArena Program**, звук — отдельным захватом приложения. Архивы сохраняются в `~/Documents/ChessArena/`.

## Журнал моделей

Кнопка **Log** вверху окна управления открывает отдельное окно, не останавливая игру. Для каждого запроса игроков и ведущего доступны время, модель, адрес API, тексты SYSTEM/USER, ответ модели, длительность и ошибка (включая HTTP-код, тайм-аут или отмену). Автоповторы записываются отдельно. В режиме ChatGPT через аккаунт показывается адрес Responses API.

Можно выбрать запись, включить фильтр ошибок, следить за новыми запросами, копировать выбранную запись или очистить журнал. Журнал хранит в памяти последние 300 запросов между партиями текущего запуска; очень длинные поля сокращаются с пометкой. Авторизационные заголовки не записываются, ключи и токены скрываются перед добавлением текста в журнал.

## Проверка

```sh
swift test
.build/debug/ChessArena --preview Preview/arena.png
```

Тесты используют фиктивные ответы и локальный HTTP-сервер, не расходуют квоту моделей. Metal, кодеки и Keychain требуют обычного локального запуска вне ограниченной песочницы.

Живой OAuth требует входа пользователя в браузере. Автоматические проверки не подтверждают права конкретного аккаунта или завершённую живую партию.

Документация: https://developers.openai.com/siwc/token-sharing-open-source/sign-in
