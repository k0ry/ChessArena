# ChessArena

Нативное шоу для macOS: шахматные партии между Grok и ChatGPT в любой комбинации, отдельное окно сцены для OBS и окно управления.

## Запуск

Откройте `ChessArena.app` в папке проекта. Чтобы пересобрать приложение:

```sh
./scripts/build-app.sh
```

1. Выберите нейросеть отдельно для белых, чёрных и **рефери / комментатора**: Grok или ChatGPT. Можно выбрать одну нейросеть для нескольких участников. Ключ xAI нужен, только если хотя бы один участник использует Grok. Комментатор озвучивает партию; легальность ходов и результат определяет шахматный движок.
2. Если ChatGPT выбран для игрока или комментатора, нажмите **Continue with ChatGPT**. В системном браузере войдите в аккаунт и разрешите ChessArena использовать план ChatGPT.
3. Вернитесь в приложение. Дождитесь «Подключено» и выберите модель из каталога аккаунта отдельно для каждого участника ChatGPT. Для Grok и режима API укажите ID модели в соответствующем поле. Выбор комментатора сохраняется между запусками.
4. Выберите **Язык эфира и озвучки**: русский или английский. Выбор сохраняется; реплики игроков, ведущий, резервные фразы и системный голос используют выбранный язык. Кнопка **Проверка тона** позволяет прослушать голос до старта.
5. Нажмите **Начать игру**. Начнётся непрерывная серия партий. **Стоп** отменяет запросы, останавливает звук и отключает запуск следующей партии.

Зависший запрос игрока отменяется через 10 минут (600 секунд). Ошибки соединения и API повторяются автоматически с той же позиции через 3, 6, 12, 24, 48, затем 60 секунд. Запоздавший ответ отменённого запроса не делает ход. Ошибка ключа или квоты остаётся видна в управлении: автоповтор не восстанавливает права доступа, но продолжит игру после исправления подключения. У ведущего отдельный тайм-аут 90 секунд с резервной фразой на выбранном языке.

Общий счёт постоянно виден сверху по центру. Победа приносит одно очко, ничья — по половине. Счёт серии сохраняется между запусками и сбрасывается кнопкой «Начать новую серию». После завершения партии доска остаётся видна: комментатор произносит короткий итог. Затем появляется заставка победителя или ничьей со счётом и отсчётом: через 30 секунд автоматически стартует новая партия. Остановка во время отсчёта отменяет перезапуск. Для каждой партии создаётся отдельный архив.

Нейросеть выбирается до начала партии; модель можно исправить на паузе перед продолжением. Кнопка **Закрыть приложение** внизу окна управления (⌘Q) завершает приложение целиком, включая окно сцены.

Вход использует официальный OAuth для локальных приложений, PKCE, проверку state/nonce и подписи ID token. Возврат — на локальный адрес `127.0.0.1` со случайным портом. Сессия ChessArena хранится отдельно в Keychain; приложение не читает авторизацию Codex или браузерные cookies. Доступ к плану зависит от аккаунта и разрешений OpenAI. Если macOS запрашивает доступ к связке ключей, подтвердите его в системном окне.

Альтернативный режим — собственный API-ключ OpenAI; он включается переключателем в управлении. API-ключ и вход через ChatGPT используют разные способы оплаты и доступа.

## Gemini через локальный CLI

В панели белых или чёрных выберите **Gemini**. Приложение запускает официальный **Antigravity CLI (`agy` 1.3.3)** на этом Mac; SSH, удалённый bridge, адрес сервера и ключ Gemini не используются.

1. Установите [официальный CLI](https://antigravity.google/docs/cli/install/), если он отсутствует. ChessArena ищет `~/.local/bin/agy`, `/opt/homebrew/bin/agy` и `/usr/local/bin/agy`; другой файл можно выбрать кнопкой **Выбрать файл**.
2. Нажмите **Войти через Google**. В открывшемся локальном терминале завершите штатный вход CLI нужным аккаунтом. Пароли и коды вводятся только в официальном сценарии; приложение не читает и не переносит токены.
3. В `/config` CLI оставьте **Use AI Credits** выключенным. Приложение проверяет настройку перед запросом и не включает расход дополнительных кредитов.
4. Нажмите **Обновить модели**, выберите модель отдельно для каждой стороны, затем **Проверить модель**. Проверка расходует один короткий запрос из доступной квоты аккаунта. Каталог сам по себе не подтверждает доступ: галочка появляется только после завершённого ответа с легальным тестовым ходом.
5. Начните игру. На ошибке Gemini партия остаётся на паузе; после исправления подключения нажмите **Продолжить партию**. Модель можно изменить и проверить на паузе. Ведущий сохраняет существующий выбор Grok/ChatGPT.

CLI запускается отдельным процессом на каждый ход, в новом временном каталоге, с шахматным агентом без инструментов. Глобальные hooks, MCP, плагины и пользовательские инструкции, обнаруженные проверкой, блокируют запрос; приложение не переписывает настройки Antigravity. Контекст содержит позицию, легальные ходы, историю и собственные заметки данного игрока. Ответ обрабатывается по [документированному JSON-формату CLI](https://antigravity.google/docs/cli/headless/); при тайм-ауте, отмене или закрытии приложения завершается группа процессов запроса. Ошибки CLI не засчитываются как нелегальные ходы и не запускают автоматические повторные запросы.

Доступ к модели и тип квоты определяет Google-аккаунт. Успешный тест подтверждает ответ модели, но не подтверждает наличие платного плана. Если Google отклоняет регион или квоту, приложение показывает причину без перехода на API-ключ, сервер или другую модель. Проверенный локальный запрос 11 октября 2026 года вернул `e2e4`; полная живая партия Gemini ещё не проверена.

## Автосохранение

Состояние автоматически записывается после каждого изменения игры и настроек в `~/Library/Application Support/ChessArena/session.json`; время партии обновляется раз в секунду. Сохраняются позиция со всеми шахматными правами, история ходов и ответов игроков, очередь хода, ошибки недопустимых ходов, счёт и состояние серии, выбранные модели, язык, поворот и масштаб доски. Ключи и OAuth-сессия хранятся отдельно в Keychain.

При запуске доска восстанавливается сразу. После перезапуска приложение ждёт действия пользователя: запросы моделей и отсчёт до следующей партии не запускаются автоматически. **Продолжить партию** возобновляет незавершённую игру из сохранённой позиции с прежними историей, временем и счётом. Время, пока приложение было закрыто, не добавляется ко времени партии. Завершённую партию продолжить нельзя; её результат повторно не засчитывается.

Кнопки управления:

- **Продолжить партию** — продолжает незавершённую игру после перезапуска, остановки или ошибки подключения.
- **Начать новую партию** — начинает с исходной позиции, сохраняя общий счёт серии. Незавершённая предыдущая партия не приносит очков.
- **Начать новую серию** — начинает с исходной позиции и сбрасывает счёт в 0:0.
- **Стоп** — прекращает запросы и сохраняет позицию для дальнейшего продолжения.

Новая партия или серия также доступны во время игры; текущий запрос отменяется, прежний архив закрывается. Если подключение требует исправления, текущая партия и счёт сохраняются. Пока приложение работает, после завершённой партии сохраняется существующий автоматический переход к следующей через 30 секунд.

Файл заменяется атомарно. Ошибка записи показывается в управлении; нечитаемый файл сохраняется отдельной копией для восстановления. После перезапуска запись видео идёт в новый архив, без перезаписи предыдущего; PGN и журнал комментариев сохраняют историю восстановленной партии.

## Сцена

Партия идёт без периодических обзоров и пауз каждые пять минут. Итоговая карточка появляется только после завершения игры.

Металлические фигуры с голубыми и янтарными световыми акцентами, узнаваемые силуэты, плавные ходы и неоновая платформа. Взятия, рокировка, превращение и взятие на проходе отображаются из принятой судьёй позиции.

Камера: перетащите доску левой кнопкой мыши, чтобы повернуть ракурс; колесо мыши, прокрутка или жест масштабирования на трекпаде приближает и отдаляет доску. После ручного изменения автоматическое движение камеры отключается, выбранный ракурс сохраняется между партиями. **Сбросить вид** возвращает исходный ракурс и автоматическое движение. Для перемещения самого окна используйте верхнюю полосу, как раньше.

OBS: захват окна **ChessArena Program**, звук — отдельным захватом приложения. Архивы сохраняются в `~/Documents/ChessArena/`.

Кнопка **Повторить запрос** отменяет текущую попытку и немедленно повторяет тот же запрос игроку, чей сейчас ход: с теми же моделью, промптом и позицией. Она работает во время ожидания ответа или задержки автоповтора. Запоздавший ответ отменённой попытки игнорируется. Во время комментария ведущего, после завершения партии и после остановки кнопка недоступна. В Log появляются отменённая попытка и новый запрос.

## Журнал моделей

Кнопка **Log** вверху окна управления открывает отдельное окно, не останавливая игру. Для каждого запроса игроков и ведущего доступны время, модель, адрес API, тексты SYSTEM/USER, ответ модели, длительность и ошибка (включая HTTP-код, тайм-аут или отмену). Автоповторы записываются отдельно. В режиме ChatGPT через аккаунт показывается адрес Responses API.

Можно выбрать запись, включить фильтр ошибок, следить за новыми запросами, копировать выбранную запись или очистить журнал. Журнал хранит в памяти последние 300 запросов между партиями текущего запуска; очень длинные поля сокращаются с пометкой. Авторизационные заголовки не записываются, ключи и токены скрываются перед добавлением текста в журнал.

## Проверка

```sh
swift test
.build/debug/ChessArena --preview Preview/arena.png
```

Тесты используют фиктивные ответы и локальный HTTP-сервер, не расходуют квоту моделей. Metal, кодеки и Keychain требуют обычного локального запуска вне ограниченной песочницы.

Живой OAuth требует входа пользователя в браузере. Автоматические проверки не подтверждают права конкретного аккаунта или завершённую живую партию.

Документация: https://developers.openai.com/siwc/token-sharing-open-source/sign-in

### Журнал сети

Кнопка **Log сети** открывает отдельное окно с последними 500 операциями с момента запуска: запросами Grok/OpenAI, потоком ответов ChatGPT, обменом/обновлением OAuth-сессии, загрузкой каталога и проверкой подписи входа, а также вызовами Gemini CLI. Для каждой операции видны время, адрес и метод, ожидание, длительность, HTTP-статус, размер данных и безопасная причина ошибки. Для CLI показывается код завершения процесса; его внутренние HTTP-запросы приложению не видны.

Есть фильтр **Только ошибки**, автоматическое выделение новых записей (**Следить**), копирование выбранной записи или всего отфильтрованного журнала и очистка. Журнал хранится только в памяти и очищается при выходе. Заголовки, параметры URL, тела запросов/ответов, OAuth-коды, ключи, токены и сырой вывод CLI не записываются. Содержимое сообщений моделей по-прежнему доступно в отдельном **Log**.

Текст ведущего расположен под временем партии. Внизу доски показана заметка самому себе (`self_notes`), переданная в текущий запрос думающего игрока; на первом ходу или после очистки заметки выводится пояснение. Заметки сопернику и ведущему не передаются.

При взятии фигура взлетает по дуге с вращением и плавно исчезает за краем доски; в момент удара появляется короткое световое кольцо. Эффект работает и для взятия на проходе. При новой позиции или завершении анимации временные фигуры удаляются.

Комментатор говорит в духе доктора Хауса: сухой сарказм, язвительные наблюдения о ходах и редкие медицинские метафоры. Реплики и итог партии короткие, без цитат из сериала и выдуманных шахматных фактов. Если модель не отвечает, звучит резервная реплика в том же тоне на выбранном языке. Счёт фиксируется сразу после результата, но заставка и 30-секундный отсчёт начинаются только после итогового комментария.
